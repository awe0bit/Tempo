# 使用与设置

安装后可以直接使用本地任务和计时。同步与 AI 都是可选项，无需先配置它们。

下面的入口以当前 iOS 客户端为主；其他平台的布局和可用选项可能不同。

## 任务与日历

- **收集箱**：先记录待办，再补充备注和日期。
- **今天**：选择日历中的日期，查看当天安排。可展开月历或收起为周历。
- **完成与删除**：完成后任务会保留完成状态；左滑可删除任务，误删时使用提示中的“撤销”。

任务先保存在设备上，离线时也可以记录和修改。

## 工具

### 番茄钟

进入“工具 → 番茄钟”，选择番茄计时或正计时，再点击开始。计时过程中可以暂停或停止。

在“设置 → 番茄钟”调整专注时长、每日目标和长休息间隔；在计时页面打开专注统计，查看记录。

iOS 支持通过锁屏实时活动和灵动岛查看计时状态。这些功能还取决于设备、系统权限和安装包签名，见 [iOS 安装说明](IOS_PRIVATE_SIGNING.md)。

### RSS 阅读

1. 进入“工具 → RSS”。
2. 打开右上角更多菜单，添加 RSS / Atom 订阅地址。
3. 刷新来源，选择文章阅读。
4. 需要摘要或翻译时，先完成下方的 AI 配置。

应填写订阅地址，而不是网站首页。刷新失败时，可先用浏览器确认该地址能返回订阅内容，且不要求登录。

## 外观与语言

“设置 → 外观”可选择跟随系统、浅色或深色模式。

iOS 界面支持简体中文和 English，默认跟随系统。只修改 Tempo 的语言时，打开 iOS 系统设置中的 Tempo 应用页面，选择“语言”，再重新进入应用。如果没有该选项，先检查系统是否已添加所需语言。

“设置 → 日期与日历”可调整一周的起始日、节日和任务标记。“设置 → 功能模块”支持长按拖动底部入口排序；当前 iOS 底部入口为收集箱、今天、工具和设置，番茄钟与 RSS 位于工具内。

## 多设备同步

只在一台设备使用时，可以跳过本节。需要同步时，先 [部署自己的同步服务](DEPLOYMENT.md)，再 [生成配对二维码](PAIRING.md)。

1. 在服务器终端生成二维码。
2. 在 iOS 打开“设置 → 自托管同步 → 扫码配对”。
3. 允许相机访问，对准二维码。
4. 确认显示的是自己的服务器，点击“确认配对”。

应用会验证连接、保存配置并开始同步。不提供手动填写服务器地址和密钥的入口，应用也不能生成配对码。二维码 5 分钟内有效，只能使用一次；另一台设备需要在服务器重新生成新码。

配对后可查看当前服务器、设备名称和同步状态，切换自动实时同步，或点击“立即同步”。要换服务器就重新扫码；确认前请注意本机数据会按同步规则与新服务器合并。

旧安装包需要升级到支持扫码的 iOS 版本。原有连接会保留，不会因页面更新清空配置。其他平台是否支持扫码，以对应客户端为准。

iOS 在后台可能被系统挂起，回到前台后再同步，不保证后台持续在线。

## AI 助手

进入“设置 → AI 助手”，选择 OpenAI、DeepSeek 或兼容接口，填写 API 地址、模型名称和 API 密钥。

- 地址和模型名称使用服务商提供、且自己的账号有权访问的值。
- RSS 摘要提示词可留空，应用会使用内置提示词。
- 点击“保存”保存配置，或“保存并测试”检查连接。
- 已有密钥时，输入框留空可保留原值。

AI 为可选功能；没有配置或调用失败，不影响基本任务和计时。服务商可能单独收费，使用前请了解对应服务的费用和隐私规则。

进行摘要或翻译时，相关文章内容会发送给所配置的 AI 服务。其他客户端如提供自托管 AI 选项，可按 [部署指南](DEPLOYMENT.md#环境变量) 配置服务器代理；当前 iOS 服务商选择器不提供该入口。

## 数据与更新

### 数据保存在哪里

- 默认保存在设备本地；开启同步后，任务、专注状态和 RSS 订阅及阅读状态也会保存在自己的服务器。
- RSS 文章正文由客户端获取并缓存在本机，不作为正文文件上传同步服务。
- 外观、导航顺序等设备偏好，以及同步密钥和 AI 密钥，不随任务同步。
- 同步不是备份。卸载应用可能丢失尚未上传的数据，更换设备或清理数据前请先确认同步和备份。

### 更新应用

在“设置 → 关于 Tempo”检查当前平台的安装包更新。各平台可能分批发布，不需要因其他平台更新而重装自己的客户端。

iOS 的兼容页面更新会自动检查和下载，在下次重新启动应用时生效；更新失败时仍可继续使用已安装内容。系统导航、原生控件、权限、小组件和灵动岛等原生功能的变更，需要安装新版 IPA。

覆盖安装请保持原来的应用标识和签名方式。不要先卸载再更新，否则可能清除本地数据。

## 常见问题

| 问题 | 先检查 |
| --- | --- |
| 找不到番茄钟或 RSS | 当前 iOS 入口在“工具”中 |
| 扫码配对失败 | 服务器是否已更新、二维码是否过期或已使用、网络是否可用 |
| 另一台设备没有任务 | 是否配对到同一服务器、自动同步是否开启 |
| RSS 刷新失败 | 是否使用有效订阅地址，来源是否要求登录 |
| AI 连接失败 | API 地址、可用模型、密钥权限和服务额度 |
| 灵动岛或小组件不可用 | 系统权限，以及主应用和扩展的签名是否完整 |
| 更新无法覆盖安装 | 新旧应用标识、签名身份是否兼容 |

仍无法解决时，请在 [GitHub Issues](https://github.com/awe0bit/Tempo/issues) 提供平台、版本和复现步骤，不要上传密钥或私人内容。
